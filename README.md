# Celebrity University Database

## Project Overview

The Celebrity University Database is a MySQL database developed as a school final project. It models celebrities enrolled in university courses, tracking their academic information, including course enrollment, semester dates, and scores.

The project demonstrates relational database design, SQL querying, GPA calculations, and data analysis through SQL views.

## Features

- **Relational Database Structure:** Organizes celebrity, course, semester, and academic score information into related tables.
- **GPA Calculations:** Calculates first-semester GPAs directly within the database.
- **GPA Reporting View:** Displays first-semester GPA results for enrolled celebrities.
- **Course GPA Rankings:** Uses a SQL view to identify the top three GPAs within each course.
- **Data Relationships:** Uses database keys and relationships to connect related records.

The purpose of this project was to apply database design and SQL programming concepts to a structured academic data scenario. It demonstrates the ability to organize relational data, perform calculations within a database, and create views that present useful information for analysis.
